# 实验 04-数码管动画（2026-10-24）

## 目标

用户指令「试一下数码管的动画」。8 位数码管动态扫描显示一个自增计数器，同时把数值发到调试台，板子与网页互相对账。

## 设计

- 计数器每 ~0.1s +1（实测 133ms），显示十进制、前导零消隐（显示「789」而非「00000789」）。
- 动态扫描：每帧 8 位逐位点亮 ~1ms/位（~90Hz，无闪烁），切位选前清段码防鬼影。
- 同步上报：每次 +1 发终端 `t=<计数>` 与 `v: <计数>`（单序列曲线 = 上升楼梯线）。
- 硬件映射按普中 A2 / HC6800-ES 通用接法编写，main.c 内明确标注 [推断]；真机验收通过后转正并写入 项目.md：
  - 段码 = P0（经 74HC245，共阴编码 1=亮）
  - 位选 = 74HC138，A/B/C = P2.2/P2.3/P2.4，Y_i 低有效选第 i 位，**Y0 = 左起第一位（无镜像）**
  - P2.2-4 与 LED 模块共用：扫描时 LED 位 2-4 闪动属正常

## 实测与验证

| 项 | 结果 |
|---|---|
| 编译 build-…（1 轮过） | 0 Error，L16×1（uart_curve2 uncalled 良性），code 990 |
| 烧写 flash-1792841071560 | 成功（attempts 1，一次冷启动握手） |
| 终端 t= 连续性 | 227 个连续样本严格 +1，0 断点（跨 10^8 回绕安全） |
| 曲线 | 楼梯线 552→789 稳定爬升，7.5 Hz 采样（见 曲线-计数器楼梯.png） |
| 实物验收 | 用户确认：计数节奏、位序、前导零消隐、无闪烁无鬼影 全对 ✓ |

计数步进实测 ~133ms（设计 ~100ms）：帧耗时 ≈11.1ms 略超估算（delay_1ms 标定差 + 每位切换开销）。不影响效果；要精确 100ms 需换定时器基准（见遗留）。

## 例外项清单

1. **计数步进 133ms vs 设计 100ms**：帧耗时长于估算所致，验收以实物效果为准，用户通过。
2. **验收截图 hasBoot=false**：页面 SSE 无历史回放，无头 Chrome 开页晚于固件 boot 行，终端看不到 `tube04 counter` 属正常。
3. **[推断]→实测 闭环**：数码管映射是项目.md 维护规则启用以来第一个「推断编写 → 真机验收 → 转正」的完整闭环，映射原文曾逐字标注在 main.c 注释里。
4. 探针 Chrome 清理：bdic 文件锁延迟释放，首轮 Remove-Item 报错，进程确认死后补删干净。
5. LED 位 2-4 闪动已在验收语中预告，用户无疑议。

## 遗留 / 边界

- 精确计数节奏：需 Timer0 中断驱动扫描（注意与 uart 阻塞打印互斥——现方案打印发生在帧间，冻结 ~12ms 不可感知；换中断后要处理打印期间的显示）。
- 曲线楼梯线长跑持续上涨（计数 mod 10^8 回绕，不会溢出）。
- 动画变体（跑马数字、倒计时、dp 呼吸、时钟）需要时另开实验 NN。
